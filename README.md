# IGES Hotel and Suites API

An ASP.NET Core 9 backend for IGES Hotel and Suites in Warri, Delta State, with independently managed branches.

Implemented: public branch selection, dated room availability, room/bathroom photo uploads, room specifications and categories, specific-room reservations, and public kitchen/pool/activity/bar/lounge listings.

Database access, Identity persistence, repositories, mappings and the complete migration history now live in **NoName_Hotel.Infrastructure**.

See [the developer guide](docs/IGES.md) for setup, migration transition notes, architecture, endpoint contracts, administrator workflows and verification commands. This repository is a backend API; customer and administrator screens are not included.
